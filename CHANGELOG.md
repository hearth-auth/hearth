## [Unreleased]

### Added

- **Release signing workflow** (`.github/workflows/release.yml`) — every `v*` tag now
  produces signed release artifacts via cosign keyless OIDC signing:
  - Multi-platform binaries: `linux-amd64`, `linux-arm64`, `darwin-amd64`, `darwin-arm64`
  - CycloneDX 1.4 SBOM (`hearth-sbom.cdx.json`) generated by `cargo-cyclonedx`
  - Per-artifact cosign detached signatures (`.sig`) and certificates (`.pem`) recorded
    in the Sigstore Rekor public transparency log
  - SLSA L1 provenance attestation (`hearth-multiple.intoto.jsonl`) via
    `slsa-github-generator/generator_generic_slsa3.yml`
  - All 16+ artifacts uploaded to the GitHub Release automatically
- **`docs/guides/verify-release.md`** — operator guide for verifying binary signatures,
  SLSA provenance, Rekor transparency log entries, and importing the SBOM into SCA tooling
- **`SECURITY.md`** — security policy with vulnerability reporting process and cosign
  signing identity (`--certificate-oidc-issuer` / `--certificate-identity-regexp`) for
  offline verification
