{# Reusable sortable column header for admin tables. Renders a whose link toggles sort direction, preserves the active search query + page size across navigation, and exposes `aria-sort` for assistive technology. Askama imports are hermetic (the macro cannot read caller context), so every value is passed explicitly. Usage from any list template: {% import "ui/admin/_sortable_th.html" as sortable %} ... {% call sortable::th("Email", "email", sort_field, sort_dir, list_url, search_query, pagination.per_page) %} Params: - label: visible header text - col: sort key emitted as `?sort={col}` (must match a server SortField) - active: currently-sorted column key (String; empty when unsorted) - dir: current direction, "asc" | "desc" - base_url: list URL the header links back to - q: active search query (preserved across sort clicks) - per_page: active page size (preserved across sort clicks) #} {% macro th(label, col, active, dir, base_url, q, per_page) %} {% let is_active = active == col %} {{ label }} {% if is_active %} {% if dir == "asc" %} {% else %} {% endif %} {% else %}{% endif %} {% endmacro %}
