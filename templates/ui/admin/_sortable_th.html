Renders a whose link toggles sort direction via HTMX, preserves the active search query + page size across navigation, and exposes `aria-sort` for assistive technology. The whole table+pagination region MUST be wrapped in a single element whose stable id is passed via `region_id`. Sort links return a full-page response; `hx-select` extracts that entire region and swaps it as one unit — thead, tbody, AND the pagination bar update together, so no control is ever left showing stale state (HEA-1615). The live-search form and the pagination links target the SAME region id, which is what keeps search, sort, and pagination consistent when combined. The search box is deliberately OUTSIDE the region so an in-place swap never steals focus or clobbers the query the user is typing. The sort link carries the active query via `hx-include="input[name='q']"`; omitting `page` resets to page 1, which is the correct behavior for a fresh sort. Returning a full page (rather than a bare ``/`` fragment) is required because DOMParser.parseFromString strips table structural elements that appear outside a `` context (HEA-1643).
