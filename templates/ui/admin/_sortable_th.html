{#- Reusable sortable column header for admin tables. Renders a whose link toggles sort direction via HTMX, preserves the active search query + page size across navigation, and exposes `aria-sort` for assistive technology. The that contains these headers MUST carry id="users-thead". The HTMX `hx-select-oob` attribute on the sort link selects the updated thead from the full-page response and swaps it out-of-band, so `aria-sort` values and the active-column caret stay accurate after every partial swap — without a full page reload or a dedicated partial endpoint. Askama imports are hermetic (the macro cannot read caller context), so every value is passed explicitly. Usage from any list template: {% import "ui/admin/_sortable_th.html" as sortable %} ... {# inside #} {% call sortable::th("Email", "email", sort_field, sort_dir, list_url, search_query, pagination.per_page) %} Params: - label: visible header text - col: sort key emitted as ?sort={col} (must match a server SortField) - active: currently-sorted column key (String; empty when unsorted) - dir: current direction, "asc" | "desc" - base_url: list URL the header links back to - q: active search query (preserved across sort clicks) - per_page: active page size (preserved across sort clicks) -#} {% macro th(label, col, active, dir, base_url, q, per_page) %} {%- let is_active = active == col -%} {{ label }} {%- if is_active -%} {%- if dir == "asc" -%} {# ascending caret: arrow up #} {%- else -%} {# descending caret: arrow down #} {%- endif -%} {%- else -%} {# neutral dual-caret: column is sortable but inactive #} {%- endif -%} {%- endmacro -%}
