{#- Reusable sortable column header for admin tables. Renders a whose link toggles sort direction via HTMX, preserves the active search query + page size across navigation, and exposes `aria-sort` for assistive technology. The and MUST carry stable HTML ids passed via `thead_id` and `tbody_id`. Sort links return a full-page response; `hx-select` extracts the tbody and `hx-select-oob` updates the thead aria-sort in place — all without a full page reload. Returning a full page (rather than a bare ``/`` fragment) is required because DOMParser.parseFromString strips table structural elements that appear outside a `` context (HEA-1643). A full page keeps all elements properly nested so the browser parser preserves them. Askama imports are hermetic (the macro cannot read caller context), so every value is passed explicitly. Usage from any list template: {% import "ui/admin/_sortable_th.html" as sortable %} ... {# inside / #} {% call sortable::th("Email", "email", sort_field, sort_dir, list_url, search_query, pagination.per_page, "users-tbody", "users-thead") %} Params: - label: visible header text - col: sort key emitted as ?sort={col} (must match a server SortField) - active: currently-sorted column key (String; empty when unsorted) - dir: current direction, "asc" | "desc" - base_url: list URL the header links back to - q: active search query (preserved across sort clicks) - per_page: active page size (preserved across sort clicks) - tbody_id: HTML id of the element (without leading #) - thead_id: HTML id of the element (without leading #) -#} {% macro th(label, col, active, dir, base_url, q, per_page, tbody_id, thead_id) %} {%- let is_active = active == col -%} {%- endmacro -%}
